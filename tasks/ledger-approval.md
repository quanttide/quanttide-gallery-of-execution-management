# 量潮课堂实训基地账本配套审批

## 背景

量潮课堂实训基地账本记录实训执行情况，业务系统需要可信记录。当前账本记录缺乏审批依据，业务系统无法确认记录可信，需要补充配套审批。

## 目标

以审批为事实源，为业务系统提供可信记录：账本记录 → 配套审批 → 对账一致。

## 角色分工

- **产品经理**：负责制作——设计审批事项与审批单，覆盖账本记录
- **课程助教**：负责验收——核对账本记录与实训实际执行，给出审批结果
- **全栈工程师**：以审批为事实源对账——比对业务系统记录与审批结果，不一致时以审批为准修正

## 验收标准

- [ ] 产品经理制作审批单，覆盖全部账本记录
- [ ] 课程助教完成验收，审批记录可追溯
- [ ] 全栈工程师对账一致，业务系统采用审批结果作为可信记录
