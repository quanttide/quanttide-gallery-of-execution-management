# 量潮课堂实训基地账本配套审批

## 背景

量潮课堂实训基地账本记录实训执行情况，业务系统需要可信记录。当前账本记录缺乏审批依据，业务系统无法确认记录可信，需要补充配套审批。

## 目标

以审批为事实源，为业务系统提供可信记录：账本记录 → 配套审批 → 对账一致。

## 角色分工

- **产品经理**：负责制作——设计审批事项与审批单，覆盖账本记录
- **课程助教**：负责验收——核对账本记录与实训实际执行，给出审批结果
- **全栈工程师**：以审批为事实源对账——比对业务系统记录与审批结果，不一致时以审批为准修正

## 五个阶段

### 1. 决策

确定配套审批方案：以审批为事实源，账本记录与业务系统记录均以审批结果为准。

### 2. 计划

产品经理负责制作：设计审批事项与审批单，覆盖账本记录。

### 3. 执行

实训执行并登记账本记录：账本如实记录实训执行情况，作为审批验收对象。

### 4. 评审

课程助教负责验收：核对账本记录与实训实际执行，给出审批结果。

全栈工程师以审批为事实源对账：比对业务系统记录与审批结果，不一致时以审批为准修正。

### 5. 复盘

回顾审批-对账全流程，改进审批模板与对账规则，沉淀为业务系统可信记录基线。

## 验收标准

- [ ] 决策明确审批为事实源
- [ ] 产品经理制作审批单，覆盖全部账本记录
- [ ] 课程助教完成验收，审批记录可追溯
- [ ] 全栈工程师对账一致，业务系统采用审批结果作为可信记录
- [ ] 复盘输出改进项
